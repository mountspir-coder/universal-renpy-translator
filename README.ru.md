# Universal RenPy Translator

**Читать на других языках:** [English](README.md) | [简体中文](README.zh.md) | [Español](README.es.md) | [Français](README.fr.md) | [日本語](README.ja.md) | [العربية](README.ar.md)

Universal RenPy Translator — это мощное кроссплатформенное десктопное приложение, предназначенное для офлайн-перевода визуальных новелл на движке **Ren'Py**. Оно использует локальные ИИ-модели через **Ollama** для обеспечения высококачественного перевода без цензуры, не отправляя ваш текст на сторонние серверы.

Этот репозиторий предназначен только для скомпилированных релизов. Исходный код закрыт.

---

## ✨ Возможности

- **100% Офлайн и безлимитно:** Не требуются API-ключи, нет ограничений по символам. Ваши тексты никогда не покидают ваш компьютер, а перевод никогда не прервется из-за ошибок сервера.
- **Перевод 18+ без цензуры:** Использует мощные локальные ИИ-модели (HY-MT1.5 и Hy-MT2) и встроенный глоссарий мата, чтобы сохранить оригинальный тон, сленг и взрослый контент без искусственного смягчения.
- **Внедрение оверлея в игру:** Встраивает плавающую кнопку переключения языка прямо в игру, позволяя бесшовно переключаться между оригинальным и переведенным текстом.
- **Все в одном и настройка в 2 клика:** Автоматически распаковывает RPA-архивы, декомпилирует файлы `.rpyc` и позволяет запускать переведенную игру прямо из приложения.
- **Широкая поддержка Ren'Py:** Безупречно работает с движками Ren'Py 6, 7 и 8+.
- **Определение исходного языка:** Автоматически определяет язык оригинальных файлов игры, чтобы предотвратить ошибки перевода.
- **Регулировка размера шрифта в игре:** Позволяет динамически изменять размер текста в игре, чтобы он подходил под любой интерфейс.
- **Умный контекст (CTX):** Передает предыдущие строки диалога ИИ, чтобы сохранить повествовательную связность и правильное использование местоимений.
- **Инкрементальный перевод (Diff):** Обновляет перевод для новых глав игры без необходимости переводить всю игру с нуля.
- **Определение пола персонажей:** Автоматически определяет пол говорящего для применения правильных грамматических форм (критически важно для русского и других языков с родами).
- **Встроенный QA-инспектор:** Автоматически сканирует файл перевода на предмет потерянных тегов, несбалансированных скобок и слишком длинных строк.
- **Визуальный редактор (CAT):** Табличный редактор для ручной правки перевода и исправления проблем QA прямо внутри приложения.
- **7 языков интерфейса:** Английский, Русский, Испанский, Французский, Японский, Китайский и Арабский.

## 📥 Скачивание и установка

1. Перейдите в раздел **[Releases](../../releases/latest)** (Релизы) в правой части этой страницы.
2. Скачайте последний файл `Universal-RenPy-Translator.zip`.
3. Распакуйте архив в любую папку на вашем ПК (не запускайте `.exe` напрямую из архива).
4. Запустите `Universal RenPy Translator.exe`.

### Предварительные требования
На вашем компьютере должен быть установлен и запущен **Ollama**.
1. Скачайте и установите Ollama с сайта [ollama.com](https://ollama.com).
2. При первом запуске программа предложит вам скачать необходимую ИИ-модель (`huihui_ai/hy-mt1.5-abliterated:7b`).

## ⚠️ Важно: Ложные срабатывания антивируса

Поскольку это приложение скомпилировано с помощью PyInstaller и **не имеет платной цифровой подписи**, Windows Defender и некоторые антивирусы могут выдавать ложное срабатывание (например, "Trojan:Win32/Wacatac" или "Wacapew").

**Это известная проблема для всех исполняемых файлов на базе Python.** Приложение абсолютно безопасно и не содержит вредоносного кода.

**Как исправить:**
1. Разрешите файл в вашем антивирусе (добавьте папку в Исключения).
2. Если вы используете Windows Defender, вы можете отправить файл в Microsoft как ложное срабатывание. Обычно они исправляют это в течение 24 часов.
